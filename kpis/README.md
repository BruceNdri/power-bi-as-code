# KPIs et pages du rapport

Ce dossier décrit **ce que le rapport doit montrer**, avant de l'implémenter.

| Fichier | Contenu |
|---|---|
| `kpis.md` | Catalogue des KPI : définition, calcul, format, source |
| `pages.md` | Pages du rapport : objectif, visuels, filtres, KPI utilisés |

Flux de travail :

1. On définit les KPI et les pages ici.
2. On produit la maquette HTML du rendu visé dans `ui/`.
3. On implémente les mesures DAX dans `ProjetTest.SemanticModel/` et les pages dans `ProjetTest.Report/`.

Statuts utilisés : `à faire` · `en cours` · `implémenté`.
